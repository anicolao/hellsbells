# Historical evaluation sources

These source snapshots retain the exact SHA-256 hashes recorded in the existing RL-v3 evaluation reports. The reports' `archivePath` fields point here where the live engine or policy has since changed.

Those results describe the previous five-round, score-selected-dealer rules. They are not a performance claim for the new 6/8/5-round games. Model weights are unchanged; current legality and full-game tests exercise the new rules.
