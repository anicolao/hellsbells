# Companion power-card frame

Generated with the built-in `image_gen.imagegen` tool using the original power frame and indexed playing frame as references. `frame-v2-source.png` is the selected 1008 × 1560 RGBA image. `scripts/prepare-power-review.ts` pads it to exact 1008 × 1584 (56:88), without stretching, and derives the filled silhouette. The reusable `BridgePowerCard.svelte` places live names and rule text above the original portraits and beneath this engraving. The proposal is opt-in through `GameCard`'s `powerDesign="bridge"` property.
